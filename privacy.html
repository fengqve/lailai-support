隐私政策

生效日期：2026 年 8 月 20 日

我们不收集你的个人数据

赖赖番茄钟不要求注册账号，也没有开发者运营的数据服务器。应用不会把专注记录、休息感想、键鼠状态或其他个人数据发送给开发者。

保存在本机的数据

计时状态、自动守护设置、每日专注时长、会议保护状态和休息感想保存在这台 Mac 的应用容器中。删除应用及其容器数据后，这些记录可能无法恢复。

自动守护读取什么

为了判断你是否开始使用或离开电脑，应用读取系统提供的“距离最近一次物理键盘或鼠标输入已有多久”以及锁屏、睡眠和会话切换状态。应用不会读取或保存具体按键、鼠标位置、窗口标题、文件内容或屏幕画面。

系统功能

应用可使用 macOS 通知和登录项功能。系统会在相关设置中显示并管理这些权限。当前 macOS 版本不会把休息感想同步到开发者服务器或第三方分析服务。

政策变更

如果未来版本改变数据处理方式，本页面会在新版本发布前更新，并说明新增的数据、用途和控制方式。

Privacy Policy

Effective: August 20, 2026

We do not collect your personal data

LaiLai Pomodoro requires no account and has no developer-operated data server. Focus records, break reflections, input status, and other personal data are not sent to the developer.

Data stored on your Mac

Timer state, automatic-focus settings, daily focus duration, meeting protection, and break reflections are stored in the app container on this Mac.

What automatic focus reads

The app reads only the elapsed time since the most recent physical keyboard or mouse input, plus lock, sleep, and session-change events. It does not read or save keystrokes, pointer locations, window titles, file contents, or screen contents.

System features

The app can use macOS notifications and login items. These permissions are visible and manageable in System Settings. The current macOS version does not send break reflections to a developer server or third-party analytics service.

Changes

If a future version changes how data is handled, this page will be updated before release with the new data, purpose, and controls.
