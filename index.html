赖赖番茄钟 · LaiLai Pomodoro

帮助你专注工作，也真正休息

赖赖番茄钟是为 macOS 设计的智能工间休息助手。

常见问题

  • 需要 macOS 14 或更高版本。
  • 自动守护只读取最近一次物理键盘或鼠标输入距今多久，不记录输入内容、窗口标题或屏幕内容。
  • 专注尚未结束时，离开电脑会暂停计时；休息提醒出现后，锁屏、睡眠或退出当前会话会开始五分钟休息。
  • 会议保护开启后，自动开始会暂停，当前专注不会被自动结束。
  • 休息感想和应用设置保存在这台 Mac 上。

Support

LaiLai Pomodoro is a mindful work-and-break companion for macOS.

Quick help

  • Requires macOS 14 or later.
  • Automatic focus reads only how long it has been since physical keyboard or mouse input. It does not record what you type, window titles, or screen contents.
  • Leaving before focus ends pauses the timer. After the break reminder appears, locking, sleeping, or leaving the current session starts a five-minute break.
  • Meeting protection pauses automatic start without ending the current focus session.
  • Break reflections and app settings are stored on this Mac.

For support, open an issue in GitHub Issues.
